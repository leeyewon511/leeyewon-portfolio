## 📌 Overview

- **개발자**: 이예원 (Lee Yewon)
- **포지션**: Web Developer (Frontend / Full-Stack)
- **주요 스택**: React, Node.js, Express, MySQL, MongoDB, Docker
- **포트폴리오 특징**: 
  - 모던 다크 테마 기반의 반응형 디자인

<br />

## 🛠 Tech Stack

### Frontend
- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, SCSS, Framer Motion
- **Libraries**: Lenis (Smooth Scroll), Lucide React, Radix UI

### Backend & Database
- **Runtime & Server**: Node.js, Express
- **Database**: MySQL, MongoDB
- **Authentication**: JWT (JSON Web Token)
- **DevOps & Tooling**: Docker, Git/GitHub, Vercel

## 🚀 Getting Started

### 1. Repository Clone
```bash
git clone https://github.com/leeyewon511/leeyewon_portfolio_v1.git
cd leeyewon_portfolio_v1
```

### 2. Dependency Installation
```bash
pnpm install
# or npm install
```

### 3. Run Development Server
```bash
pnpm dev
# or npm run dev
```
- 기본 접속 주소: `http://localhost:3000`

### 4. Build for Production
```bash
pnpm build
```
